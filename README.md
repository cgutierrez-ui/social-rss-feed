# Instagram RSS URL Generator

## Description
A Python script that creates custom RSS feeds from Instagram accounts using [RSS-Bridge](https://github.com/RSS-Bridge/rss-bridge) and generates a unique URL to reference in Slack, etc. to use for RSS feed subscriptions.

## Getting Started

### Dependencies
* [RSS-Bridge](https://github.com/RSS-Bridge/rss-bridge)

### Installation
* Clone this project & run:
```
python install -r requirements.txt 
```
